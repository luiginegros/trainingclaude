⚙️ SETUP REQUIRED

Quick Setup Guide

Before you start, you'll need a few things installed on your machine. The hands-on labs require you to paste prompts into Claude and run Python code locally.

1

Get access to Claude

You'll need Claude to complete the interactive labs. Choose one:

claude.ai — free tier available, paste prompts here Anthropic Console — for API access and coding exercises
2

Install Python (3.10+)

The code examples use Python. Check if you have it:

python3 --version

If not installed: python.org/downloads

3

Install the Anthropic SDK

This is the Python library to call the Claude API:

pip install anthropic
4

Get your API key

Create one at console.anthropic.com/settings/keys, then set it:

# Mac / Linux
export ANTHROPIC_API_KEY="sk-ant-..."

# Windows (PowerShell)
$env:ANTHROPIC_API_KEY="sk-ant-..."
5

Verify it works

Run this quick test in Python:

import anthropic
client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-sonnet-4-20250514",
    max_tokens=100,
    messages=[{"role": "user", "content": "Say hello!"}]
)
print(msg.content[0].text)

If you see Claude's response, you're ready!

💡 Note: For the first few pillars, you only need claude.ai — just paste the lab prompts and follow along. The API + Python setup becomes essential from Pillar 2 onwards when you start building real agent loops.
